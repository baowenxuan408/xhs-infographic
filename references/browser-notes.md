# 浏览器实操笔记（数漫 / DeepSeek / Edge）

> "怎么点"的细节都在这里。**只在前三步卡住时才需要读。**
> 坐标是当前视口（约 1379×803）实测值，换分辨率要重新数一遍。

## 一、用哪个浏览器

- **必须用用户日常登录过的 Edge**（`browsers_list` 里 `family: edge` 的那个）。
- 内置浏览器**没有登录态**，打开 DeepSeek / 数漫都会跳登录 —— 别在那浪费时间。
- 先 `tabs_new` 开标签，之后沿用同一个 `tab_id`；标签丢了就重新 `tabs_new` 拿新 id，别猜。

## 二、Edge 桥接掉线（自己修，不用问）

症状：`browsers_list` 里看不到 edge，或所有操作报错。

```powershell
Get-Process -Name "browser-extension-native-host" -ErrorAction SilentlyContinue | Stop-Process -Force -Confirm:$false
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" "https://www.baidu.com/"
# 等 30-45 秒，Edge 会以新的 browser_id 回来
```

判定：`browsers_list` 里 `"family":"edge"` 且 `extension_version` 有值 = 连上。
⚠️ 重连后**标签页 id 全部重排**，先 `user_open_tabs` 重新认页面，不要拿旧 id 硬点。

## 三、DeepSeek（第 1 步）

- 必须**新对话**：老对话会把上一轮上下文带进来。
- 粘整段口令，只替换 `【】` 里的主题。
- 发送：点输入框 → 直接按 Enter（同一次动作），比点发送按钮稳。
- **正文读不到就截图看**（`tab_screenshot` + 看图读），不要死磕 DOM —— 死磕是最容易触发 60 秒止损的环节。
- 出全文后**立刻存盘**到 `_inspect\ds_note_<日期>_<主题>.txt`，页面刷新会丢。

## 四、数漫（第 3 步）

### 入口
- `ydtv.ai` → 「开始使用」→ 工作台
- 左侧栏「全部」直接点 **GEM 3.8 flash**
- ❌ 不搜索模型 ❌ 不点「新建对话」✅ **已有历史对话里发**

### 发送（最容易卡在这）
- 点右下角 ↑ 经常没反应，文字留在框里
- 可靠做法：**先点输入区（约 x=800, y=690）让光标进去 → 立刻按 Enter**
- 判断：输入框文案还在 = 没发出去；输入框变空 + 出现「停止/生成中」= 发出去了
- 发完**追加一句**「第 2、3 页不要大标题，用副标题」（官方规则，优先于模板）

### 出图节奏
- 第一次通常只出第 1 页
- 缺页：**同一对话**补「继续生成第 2 页和第 3 页」
- 单页重发：「请把第 X 页单独重新生成一张」—— 该消息下只有一个下载按钮，物理上不会串张

## 五、查看器工具栏（第 4 步，最容易点错）

视口 1379×803 时，工具栏在**顶部 y≈30**，从左到右：

| 按钮 | x 坐标 |
|---|---|
| 展开 | ≈1213 |
| 裁剪 | ≈1258 |
| 下载 | ≈1298 |
| 关闭 | ≈1338 |

- 间距只有 40px 左右，**点偏一格就误触裁剪或关闭**（关闭会丢掉刚才的图）
- 不确定时先截一条 199×70 的顶部条，自己数一遍再点
- **第一次点常常只 hover 没真下** → 目录里没新文件就**再点同一坐标一次**，不要换位置乱点

## 六、下载（第 4 步）

前置：Edge 关掉「每次下载都询问保存位置」；目录固定 `D:\Liulanqixiazaiwenjian`。

1. 滚到卡片完整可见 → 点卡片中央打开查看器
2. 截图确认是第 i 页（看标题/副标题）
3. DOM 找 `title=下载`；找不到再用上面坐标
4. 等 3 秒 → 取最新文件 → 算校验值，与已下文件重复 = 下错

**下载前先看查看器左下角「原图 宽×高」**：出现 1024×1024 = 这张废了，**别下**，直接让数漫重做这一页。

**串张**（已验证）：连点三次拿到的三张校验值全一样 → 说明点的是同一个隐藏按钮。此时让数漫单页重发，不要继续换坐标试。

**`.crdownload` 不动**：文件头 `89 50 4E 47`（PNG 头）即数据完整，改扩展名即可。

## 六·五、账号被别人共用（已多次发生，必读）

数漫账号可能同时被另一台机器/另一个会话使用，表现有三种，全都遇到过：

| 现象 | 后果 | 判法 |
|---|---|---|
| 同一对话流里混进陌生主题的轮次（例：宾利对话里冒出「雷神 ML6PRO 键鼠」） | 往上翻会翻到不属于本批的卡片 | 卡片标题/副标题跟本批文案对不上 |
| 下载目录里出现别的主题的图（例：宾利下载目录里躺着一整套「染发洗头」） | 误归口 → docx 图文全错 | 文件名时间对得上≠内容对得上，**必须开图看画面** |
| 生成中途别人也发了请求 | 你的图排在别人后面，等更久 | 余额不动但一直没新卡片 |

**铁律：下载完一张就开图核对，不许攒齐了再一起看。**

- 核对内容 = 图面大标题是否等于本批该页标题，副标题对得上，三张风格一致
- 内容对不上 → **不是你的图**，留在原地别动（那是别人的批次），自己重新滚到本批卡片再下
- 归档前再整批看一眼三张是否同一主题、同一画风

**下载目录基线**：开工前记一次目录快照，下载后只认「快照之后新增的文件」。

```bash
ls -1 "D:/Liulanqixiazaiwenjian" > /tmp/dl_before.txt   # 开工前
# 下载后
ls -1 "D:/Liulanqixiazaiwenjian" | grep -vxF -f /tmp/dl_before.txt
```

## 八、工具边界（别硬碰）

- **写桌面必须非沙箱**：沙箱里写 `Desktop` 会被静默丢弃，写完 `ls` 复核
- Word/WPS 开着文档时写入报 WinError 5/32 → 先关文档
- 坐标点击前先截图确认；连续两次点不中就换 DOM，第三次停手
- 页面改版（按钮消失、结构变化）：不要连试，记现象 + 报「页面结构与预期不符」，由人决定改脚本还是改流程
