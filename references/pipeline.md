## 第 1 步｜DeepSeek 出文案

1. `chat.deepseek.com` → **新对话**（老对话会把上一轮上下文带进来）
2. 粘 `deepseek提示词口令 .txt` **原文整段**，只把【】里的主题换掉
3. 出全文存 `_inspect\ds_note_<YYYYMMDD>_<主题>.txt`

### 结构固定

```
大标题 → 引语 → 表情小标题 ×3 + 内容 ×3 → 最后一句
```

- 板块**固定 3 个**，多吐了在对话里回「只要前三个板块，其余删掉」，**不手工拼接**
- 表情**原样保留**，字符不改，后面跟**半角空格**

### 标题规范

- ≤ **20 字符**，8–15 最佳；**前 8–10 字含核心关键词**
- **标题里的数字必须和正文对得上**（写「3 步」就正好 3 步，对不上改标题）
- 禁忌：无意义表情、语气助词、「震惊」「99% 的人不知道」这类夸张词

### 正文规范

- **不许问答式**：不以「如何解答这个问题」行文，重构成结构化科普，脱离提问也能读
- 字数 500 左右，图信息足够时可自适应，**不硬凑**
- **生活经验要有活人感**：写实操细节 —— 不是「密封保存」，是「装保鲜袋挤干净空气，马克笔写日期」
- 板块用明确标题/序号分隔，要点短句分行，重要结论独立成段

### 正文与图的关系（官方口径，最容易写反）

| 维度 | 要求 |
|---|---|
| 信息量 | **图 > 正文**，图承载主要信息，正文是补充 |
| 覆盖面 | **正文 ⊇ 图**，图上每个点正文都要有展开，不许漏 |
| 增量 | 正文要有 **2–3 个图放不下的点**：原理解释 / 实操体验 / 数据推导 / 注意事项 |
| 自检 | 遮住图只看正文，还有独立阅读价值吗？离开图就"没东西了" = 只在重写图上的字 |

> ⚠️ 这条只管**小红书笔记正文**。**标注 docx 另算**：严格跟图走，不许加图外知识（红线 9）。两者别混。

## 第 4 步｜下载

目录 `D:\Liulanqixiazaiwenjian`。**总原则：先确认再点，禁止连点同一按钮，禁止盲点坐标。**

每张按序：

1. 滚到卡片**完整可见** → 点卡片**中央**打开查看器

4. 等 3 秒 → 取目录最新文件 → 算校验值，**与已下文件重复 = 下错**

### 每张必核（不许抽查）

- 查看器左下角「原图 宽×高」必须是 **3:4**（864×1152 / 1086×1448）
- **出现 1024×1024 方图 = 这张废了，别下载**，直接让数漫重做这一页

- 底部黑条 / 警示语**不出界**
- **落到本地后立刻开图核对画面内容**：大标题 = 本批该页标题？三张同主题同画风？对不上就是别人的批次（见 `browser-notes.md` 六·五），不要归口

### 修正轮（图面与文案对不上时）

图已经出了但**图上的字和文案说法相反**（例：图写「左侧羽毛更多」，文案写「左边少一根」），不要将就交付，走修正：

1. 先定**唯一正确答案**（查权威源），确定是图错还是文案错
2. 只重出错的那一页，话术要点名三处：**原文错在哪 → 改成什么 → 其他页不许动**
   > 第 1 页重做：图面标注现在是「左侧羽毛更多」，与文案矛盾。必须改成左侧标注「左侧羽毛更少」、右侧「右侧羽毛更多」，且画面上左翅羽毛明显稀疏、右翅明显密集。第 2、3 页保持原样不动。
3. **修正版出来必须重新逐字核对**，不许因为「它是修正版」就当 PASS —— 上一批的坑就是修正指令发了、图也重出了，但没验
4. 旧版卡片**不要删**（留证），下载时按新卡片的标题/内容认
5. 修正会再扣一张的钱，汇报里写进余额消耗

### 失败处理（最多 2 次）

- 第 1 次：换方式（DOM ↔ 坐标）
- 第 2 次：让数漫单页重发（「请把第 X 页单独重新生成一张」，该消息下只有一个下载按钮，物理上不会串张）
- 第 3 次 / 单页超 60 秒：**停手报告**，只报下好了哪几张、卡在第几页

重做话术（照抄）：
> 第 X 页重做，现在是 1024 方图而且标题被裁。必须 3:4 竖版，标题「……」完整显示在顶部不能出界，风格和第 3 页完全一致，内容不变。

### 归口后必做：放大查字，糊就锐化（2026-11-04 客户反馈"字体不清晰"）

交付前把每张的**小字区域裁剪放大 3 倍**看一眼，发虚就上超采样锐化（尺寸不变）：

```python
from PIL import Image, ImageFilter, ImageEnhance
im = Image.open('1.png').convert('RGB')
up = im.resize((im.width*2, im.height*2), Image.LANCZOS)
up = up.filter(ImageFilter.UnsharpMask(radius=2.2, percent=130, threshold=2))
up = ImageEnhance.Contrast(up).enhance(1.04)
up.resize(im.size, Image.LANCZOS).save('1.png')   # 缩回 864×1152
```

- 处理前后各出一张对比图确认：笔画变实、无白边/噪点才算过
- 属于红线 10 允许的第④类「清晰度锐化」，不用汇报申请

**交付标准**：命名只能 1/2/3 ｜ 3:4 ｜ jpg/png ｜ 全进 `桌面\数据标注`。

## 第 6 步｜质检

### 官方硬指标（错一项直接 1 分不结算）

- 比例 3:4 ｜ 格式 jpg/png ｜ 命名 1/2/3
- 清晰 720p 以上：无模糊、虚化、水印、马赛克、涂抹痕、字看不清
- 无黑边、无白底、四周无白框 ｜ 图中无错别字

### 视觉规范

- **大标题只首图放大**，第 2、3 页用明确副标题；若每页都放，格式/颜色/位置必须完全一致
- **首图**与标题强绑定、有信息量（对比图 / 清单图 / 大字报），不能是纯标题图
- **每页核心点 ≤3 个**，色块间留白，**不许「超市传单感」**（信息块堆满、字密、无呼吸）
- 三页同色调、同字体、同画风，没有一张「跳出来」
- 配图顺序 = 正文顺序，不许打乱
- 实物 / 生活经验类优先实拍质感，别做成扁平插画
- **图面不许出现任何网址、二维码、扫码引导**（红线 11）
- **分点与文案一一对应**：数量、顺序、措辞全一致，漏一个都不行
- 图上每个信息点正文都有展开；正文每个板块图都有可视化

### 客户点名的四条硬伤

| # | 硬伤 | 判定 | 处理 |
|---|---|---|---|
| ① | **画风不一致** | 同一篇里多种风格混搭，某张明显"跳出来" | 生产前先定视觉基调（主风格、表现手法、图标风格），跳出来的替换掉 |
| ② | **超市传单感 / 电商海报感** | 单张塞太多信息块、色块无呼吸、字密到阅读疲劳 | 每张 ≤3 个核心点，塞不下就加页，**不往里挤**；避免满铺式排版 |
| ③ | **图文不对齐** | 图上有正文没提，或正文有图没体现 | 图上每条要点正文都要有展开；图上多出的实用提醒要在正文补上。**图是正文的可视化，不是独立信息源** |
| ④ | **配图顺序与正文不一致** | 正文先讲 A 后讲 B，图却反过来 | 正文顺序 = 图片排列顺序；封面可当总览独立，内页必须严格同步 |

### 逐字读法

- 每张裁三段放大 2 倍逐字读
- **小字标签（卡片名 / 徽章 / 脚注）单独放大 3 倍** —— 错字高发区
- **图标标签也算字**：数字重复、前后矛盾（「1-10」+「10级」）按错字处理
- 改字只动那一小块：抹旧字 → 按底色补平 → 同款字体重排

### 只准改三样

① 错别字 ② 比例 ③ 格式。其余像素一律不碰。

## 第 7 步｜标注 docx


**格式硬要求**

- 图上带 `1./2./3.` 编号的，文档照写编号，措辞顺序跟图一致；图上分几块文档拆几块

**分类怎么定**：生活 / 科技 / 职场 / 健康 / 法律 / 教育。拿不准就问一次，不猜。
