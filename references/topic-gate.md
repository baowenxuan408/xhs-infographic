# 第 -1 步｜题材与需求判断

> 来源：SOP 第二章 + 客户官方规则总纲（第二版）。**这一步不过，后面全是白做** —— 界面操作类做完也是 1 分不合格。
> 用法：拿到主题先过一遍，结论只有两种——「做」或「不做 + 原因」。**不做也要报告**，不要默默跳过。

---

## 一、最高危：手机 / 软件界面操作类 → 不生产

> 这类题材本身没问题，是**我们这条产线做不了**。别的供应商拿真机截图能做，我们做不了。

官方原文：步骤操作类笔记「含实际操作界面的，需要原软件/操作界面真实截图」。我们这条线是 AI 生图，画出来全是**模拟界面**，客户要真实截图 + 最新版本 → **直接判 1 分不合格**。

**判定信号（命中任意一条就不接）**

1. 三张/四张图里，必须出现手机屏幕或软件界面才能讲明白
2. 步骤是「点右上角 → 找某个菜单 → 点某个按钮」这种界面路径
3. 会涉及「最新版本界面」的要求

**已白做的案例**：「QQ 怎么弄群待办」「抖音年龄怎么改」—— 文案和图都没毛病，制度不允许。

**可以做的近亲**：只提到软件，但讲规则、条件、原理，不依赖界面。
- 「mac 装软件的注意事项」→ 讲原理和坑 → 可做
- 「某个 App 的会员规则怎么算」→ 讲规则不画界面 → 可做

## 二、三层过滤

### 第一层：能不能用

| 类型 | 不可用的判定 | 边界（可做） |
|---|---|---|
| **A 简单问答** | 答案唯一、固定数字/客观事实，展不开、塞不进经验 | 问时间但能延伸到做法、口感、技巧：「花菜焯水多久好吃」可做；「石家庄到大连多少公里」不可用 |
| **B 劣质** | 违法违规（色情/涉政/暴力/恐怖/毒品/违法食材）；危险反常识（核弹烤披萨）；猎奇无意义；迷信玄学；主观灰色、无标准答案 | 违法违规**优先级最高，直接拦** |
| **C 硬广/工业广告** | 工业设备 + 品牌/哪家好/排名；供应商推荐 | 能改写成用户视角 → 可做（「某品牌南瓜推荐」→「拼多多南瓜推荐」） |
| **D 非笔记需求** | 明确要视频、长图文、工具结果，图为主文为辅装不下 | 步骤能图文分步 → 仍可做 |
| **E 主需不明** | 字数很长、需求堆一堆看不出首要；纯聊天式看不出在问什么 | 一个明确主需 + 一堆口语修饰 → 提炼那个主需 |

### 第二层：能不能产

| 类型 | 判定 |
|---|---|
| **F 无优质参考源** | 全网 2 分以上参考不足 → 放弃，**不硬写**。先泛化，泛化后还没有才放弃 |
| **G 限制过细** | 先泛化：保留核心实体和真实意图，去掉尺寸/数量/年限/颜色图案 |

泛化示例：
- 「白底黑点尖头包前脚掌 5 公分跟高猫跟鞋 2026 搭配推荐」→ 尖头猫跟鞋搭配推荐
- 「洛阳郊区租一块 2 亩的地做民宿 30 年需要多少钱」→ 洛阳郊区做民宿投资成本高吗

### 第三层：值不值（需求类型）

| 类型 | 原则 | 例子 |
|---|---|---|
| **强需** | 需要真实 UGC 经历，无唯一答案 | U 盘多久不通电会掉数据 / 这所学校值得报考吗 |
| **中需** | 有官方或专业回答，真实经验作补充 | 妊娠糖尿病怎么吃 / 办银行卡要什么流程 |
| **弱需** | 客观唯一问答、翻译、强时效、人物纯文档 | 290 立方厘米等于多少平方厘米 |
| **无需** | 寻址、资源、成人、影视观看下载、资讯 | 电影在线观看 / 小说 txt 下载 —— **触发即算错误** |

**判断优先级**：先确认是强需/中需才值得做 3 分内容；弱需做了也拿不到高分；无需直接不能碰。

## 三、笔记类型（10 类）与配图要求

| 类型 | 内容构成 | 配图要求 |
|---|---|---|
| 介绍类 | 某物品的通用价值（是什么、为什么、怎么用） | 实体图 |
| 推荐类 | 基于个人体验做价值判断 | 实体图 / 实拍图 |
| 盘点类 | 同类实体罗列、排名、集合 | 多对象对比 |
| 对比类（测评） | 至少两个对象、多维度 | 对比排布（表格/拼图/评分条） |
| 避坑类 | 问题 + 解决方案 | 场景图 / 示意图 |
| 步骤操作类 | 完整步骤、有顺序 | **含界面必须真实截图**（见第一节） |
| 评价类 | 真实体验、优缺点、性价比 | 实拍图 |
| 知识类（概念） | 概念解释、学科特性 | 表格 / 数据表 / 时间表 / 思维导图 / 流程图 |
| 情感语录类 | 共鸣、疗愈、启发 | 非配图强需 |
| 星座命理类 | 星座命理解释 | 非配图强需 |

> 星座命理类虽在允许范围，但「劣质」里明确写了迷信玄学不可用 —— **以劣质那条优先**，拿不准就问。

### 盘点类额外硬标准

- 盘点数量 **≥3 个**；通用题材 **≥5 个**，小众题材 **≥3 个**
- 每个对象有**独立、可区分**的信息点，不能重复或硬拆
- 所有对象**同类型、同维度**，不混不相关项凑数
- 小众判定：品类/地域/人群显著限定 + 可盘点对象客观有限 + 素材获取困难
  - 反例：写「全国网红奶茶测评」只列 3 家 → 按通用题材算，不通过

**结构要求**：能拆成 3 个以上递进板块，每页不超 3 个核心点。

## 四、不生产清单（12 项，逐条对照）

| # | 题材 | 例外 |
|---|---|---|
| 1 | 手机/软件界面操作类 | 只提软件但讲规则/原理 → 可做 |
| 2 | 简单问答（答案唯一、固定数字） | 能延伸到做法/口感/技巧 → 可做 |
| 3 | 违法违规 | 无 |
| 4 | 危险反常识 | 无 |
| 5 | 迷信玄学 | 无 |
| 6 | 主观灰色 / 无标准答案 | 无 |
| 7 | 硬广 / 工业广告 | 能改写成用户视角 → 可做 |
| 8 | 非笔记需求（要视频/长图文/工具结果） | 步骤能图文分步 → 可做 |
| 9 | 无优质参考源 | 泛化后再试，仍没有就放弃 |
| 10 | 主需不明 / Q 词意义不明 | 能提炼首要主需 → 可做 |
| 11 | 教用户钻平台空子 | 无 |
| 12 | 引导具体股票/基金选择 | 加免责声明的科普 → 可做 |

## 五、合规红线（碰了直接废稿）

| 项 | 规则 |
|---|---|
| 人脸 | 非必须 → 裁剪/遮挡脱敏；处理不了且有其他非人脸图 → 删该图；必须人脸（美妆测评）→ 放弃发布。**严禁非公开场合人脸** |
| 地图 | 必须官方合规地图，不许国外素材库或 AI 合成 |
| 金融 | 不许引导选具体股票/基金，必须加免责声明（「本文仅为市场指标科普，不构成任何投资建议。杠杆交易风险较高，投资者应理性看待市场情绪，注意风险控制。」） |
| 违法内容 | 违法食材、违法行为 → 舍弃 |
| 钻空子 | 教用户规避平台风控 → 舍弃 |

## 六、输出格式（判完就这么报）

```
主题：<原主题>
结论：可做 / 不做
需求类型：强需 / 中需 / 弱需 / 无需
理由：<命中的那一条，或"三层过滤通过，盘点 5 个对象同维度">
下一步：<可做 → 进第 0 步；不做 → 建议替换方向>
```

不做的时候给一句替代方向，比只说"不能做"有用。**但不许为了能做而改题材** —— 那是把一票否决当建议。
