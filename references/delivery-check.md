# 交付前自检（逐条打勾，一项不过不交）

> 来源：SOP 第十五、十六章 + 客户规则总纲第十章。**能脚本化的别用眼睛，能眼睛看的别省。**

## 三分的自查四问（先问，再勾清单）

1. 标题能不能让目标用户一眼心动、有点击欲望？
2. 封面是不是比同行更抓眼球、更有信息量？
3. 配图是真的帮用户理解，还是只为填满版面？
4. 有没有提供有信息增量的回答？能不能落地执行？真不真实？

> 三分公式：**精准标题 × 强关联配图 × 真实有用内容，图片为主、文字为辅。**
> 二分是"合格助手"：信息够用、无功无过。差别不在字数，在有没有增量。

## 一、开工前

- [ ] 过了三层过滤（能不能用 / 能不能产 / 是不是界面操作类）
- [ ] 需求类型是**强需或中需**（弱需慎重，无需不碰）
- [ ] 能拆成 3 个以上递进板块，每页不超 3 个核心点
- [ ] 找得到深链权威页面并已验过（标题含主题 + 关键词 ≥3 次）

## 二、图

- [ ] 命名 1/2/3（4），**从 1 连续**，格式 jpg/png
- [ ] 全部 **3:4**、864×1152、无黑边白底、四周无白框、720p 以上
- [ ] **大标题只首图放大**，后面用明确副标题（或全部一致）
- [ ] 首图与标题强绑定、有信息量，不是纯标题图
- [ ] 每张核心点 ≤3 个，有留白，不像超市传单
- [ ] 全部同色调、同字体、同风格，没有一张"跳出来"
- [ ] 逐张放大看过：不模糊、不虚化、无水印、无马赛克、不裁切、不压边、无错别字
- [ ] 图上信息点正文全都有对应展开
- [ ] 配图顺序与正文顺序一致
- [ ] 图面无网址、无二维码、无扫码引导（红线 11）

## 三、正文

- [ ] 标题 ≤20 字符、8–15 最佳，**前 8–10 字含核心关键词**
- [ ] 标题里的数字和正文完全对得上
- [ ] 不是问答式，脱离提问也能独立阅读
- [ ] 有 2–3 个图放不下的增量（原理 / 体验 / 数据 / 提醒）
- [ ] **遮住图只看正文，仍有独立阅读价值**
- [ ] 板块有明确标题或序号，重点独立成段
- [ ] 生活类有实操细节，不是干巴巴的结论
- [ ] 无夸张词（震惊、99% 的人不知道）

## 四、标注文档

- [ ] `分类：` `标题：` 各自独立成段；`正文：` 与引语同段
- [ ] 每个表情小标题前有空行；表情与 DeepSeek 逐字一致
- [ ] 图上编号 / 分块 / 标题词，文档一模一样有
- [ ] 文档里没有图上没有的知识（术语解释、年份、机构名、额外举例）
- [ ] **正文 / 分类 / 引语 / 板块里一个网址都没有**，只有链接区一行
- [ ] 链接区只有两行：`文本链接：` + 纯 URL
- [ ] 全文中文，无裸英文术语

## 五、合规

- [ ] 无违规内容、无灰色人情、无钻平台空子
- [ ] 有人脸 → 已脱敏或删除
- [ ] 有地图 → 官方合规地图
- [ ] 金融类 → 已加免责声明

## 六、脚本能替你做的部分

```bash
# 尺寸归口 + 校验值查重
python scripts/normalize_images.py --dir "C:/Users/baojiawen/Desktop/数据标注"

# 生成 / 重出文档
python scripts/build_docx.py --copy copy_20261103_主题.json \
  --out "C:/Users/baojiawen/Desktop/数据标注/主题.docx"

# 深链验证
python scripts/verify_link.py "<URL>" 关键词1 关键词2

# 交付自检（只读）
python scripts/check_delivery.py --dir "C:/Users/baojiawen/Desktop/数据标注"
```

**脚本管形状**：尺寸、格式、命名、编号连续、校验值查重、文档段落结构、网址越界。
**眼睛管内容**：错别字、画风、留白、传单感、首图信息量、图文对齐、正文增量。
两者不可互相替代 —— 脚本 PASS 不等于能交，肉眼顺眼也不等于格式对。
